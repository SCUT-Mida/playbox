1.3 2.5D卡牌展示区技术实现（CSS关键代码逻辑）

· 使用 perspective: 1200px + transform: rotateX(15deg) rotateY(20deg) 营造立体感。
· 底部阴影用伪元素 ::after 制作椭圆形渐变投影，随旋转角度动态偏移。
· SSR 动态粒子：Canvas 覆盖层绘制水墨粒子，循环飘落，跟随鼠标移动产生流向变化。

二、卡牌升星机制（道果九重天·细化版）

2.1 九重道果数值成长表

道果重数 消耗天道本源 消耗同名碎片 全属性加成 特殊解锁
★1→★2 2 0 +8% —
★2→★3 4 1张R / 1碎片SR +8% 解锁被动技1
★3→★4 6 2张R / 2碎片SR +10% —
★4→★5 8 3张R / 3碎片SR +10% —
★5→★6 10 4张R / 4碎片SR +12% 解锁被动技2 / 觉醒技（SSR专属）
★6→★7 15 6张R / 6碎片SR +12% 卡牌立绘增加“流光特效”
★7→★8 20 8张R / 8碎片SR +15% —
★8→★9（满星） 30 10张R / 10碎片SR +15% 解锁“化凡入圣”进化资格

总计：一张卡从1星拉到9星满，需消耗 95个天道本源 + 34张同名卡（或碎片）。单机环境下，主要通过秘境高层和活动稳定获取，培养周期约2~3周满一张SSR。

2.2 化凡入圣（品质进化）

当R卡或SR卡达到 9重满星 + 特定等级上限 时，可消耗大量天道本源进行进化：

进化路径 消耗 效果
R → SR（逸品→绝品） 天道本源×50 + 对应五行精华×30 等级上限50→70，基础属性提升至SR面板，边框变为紫金，立绘增加淡彩
SR → SSR（绝品→至品） 天道本源×100 + 天道卷轴（主线通关卷拾获取） 等级上限70→90，基础属性提升至SSR面板，边框变为彩凰流光，立绘升级为全动态水墨

设计意图：让非酋玩家通过长期养成，把本命R卡一步步培养成SSR，强化单机“陪伴感”与“养成深度”。

3.2 战斗中的动态反馈（UI动效）

事件 视觉表现 技术实现
回合开始 屏幕底部浮现水墨“第X回合”字样，缓缓消散 CSS keyframes 淡入淡出+上移
出手选择 当前出手卡牌高亮金色描边，并上浮10px class 切换 + transform
攻击命中 攻击者残影飞向目标，命中瞬间水墨飞溅（敌方闪红） JS + Canvas 飞行动画 / CSS动画
五行克制 屏幕边缘闪烁对应五行颜色（金=白、木=绿、水=蓝、火=红、土=黄），并弹出“克！”水墨大字 全屏遮罩渐变色闪烁
暴击 伤害数字放大为1.5倍，金色描边，伴随屏幕微震 CSS scale + 数字样式变化
治疗 绿色水墨涟漪从目标中心扩散至全队 CSS radial-gradient 脉冲
阵亡退场 卡牌化为墨迹飘散（水墨消散特效） Canvas粒子系统
胜利/失败 胜利：画卷缓缓展开，掉落物逐一亮相 / 失败：屏幕染红，水墨碎屑飘落 全屏过渡动画

3.3 操作交互（半自动/手动模式）

· 自动模式（默认）：AI按最优逻辑（优先克制属性、优先残血）自动施放技能，玩家仅观看。
· 手动模式：点击“集火”标记敌方目标，或点击我方卡牌头像手动选择技能施放。
· 加速开关：提供 ×1 / ×2 / ×3 倍速切换，减少重复战斗等待时间。

四、一键扫荡设计（云游挂机）

4.1 扫荡解锁条件

· 该关卡必须 3星通关（达成条件：战斗胜利 + 我方无阵亡 + 剩余血量 > 70%）。
· 玩家等级达到 20级 后解锁扫荡功能。

4.2 扫荡消耗与收益

消耗项 说明
扫荡券（神行符） 每次扫荡消耗1张，通过洞府挂机、每日任务、周常奖励大量产出（单机管够）
体力（灵气） 每扫荡1次消耗10点灵气（上限120点，每5分钟恢复1点），与手动战斗消耗一致

· 收益：直接获得该关卡 100%掉落（含精英/Boss的碎片概率），跳过整个战斗动画，弹出 “扫荡结算弹窗”，列表展示本次获得的所有资源。

4.3 批量扫荡（良心设计）

· 可一次性选择 “扫荡1次 / 5次 / 10次”。
· 批量扫荡时，以 10倍速 快速滚动展示掉落清单（模拟开箱快感），点击“一键领取”全部收入囊中。
· 若中途灵气或神行符不足，自动停止并结算已完成的扫荡次数。

4.4 扫荡券循环保障（单机无氪友好）

来源 数量 频率
洞府挂机 2~4张/小时 持续产出
每日签到 5张 每日
每日任务（活跃度宝箱） 10张 每日
周常任务 30张 每周

保证活跃玩家 扫荡券永远溢出，想刷材料随时扫，无需抠门计算。
